# Aula 2 - Front-End para Web

Este repositório reúne os exercícios e materiais desenvolvidos na Aula 2 de Front-End para Web.

## Objetivo
Aprender os fundamentos de desenvolvimento front-end, incluindo estrutura de páginas HTML, estilos CSS e interação básica com JavaScript.

## Conteúdo
- Estrutura de páginas em HTML
- Estilização com CSS
- Organização visual e layout
- Exercícios práticos de front-end

## Como usar
1. Abra os arquivos em um editor de texto ou IDE.
2. Use um navegador para visualizar as páginas.
3. Ajuste os códigos conforme os exercícios propostos.

## Tecnologias
- HTML
- CSS
- JavaScript
